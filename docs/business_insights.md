# How to present the project

Use these as interview talking points after running the analytics:

- **Cost concentration:** rank departments and diagnoses by total cost, then inspect whether high spend is volume-driven or cost-per-admission driven.
- **Readmission focus:** compare `Readmission Rate` across age bands, severity, payer type, and diagnosis. Frame it as a signal for discharge-planning review, not a clinical conclusion.
- **Operational throughput:** use average length of stay alongside admissions; a high-LOS, high-volume department is a sensible operational review candidate.
- **Data-quality maturity:** explain that duplicates were removed, labels standardized, missing cost imputed by department median, and validation assertions stop invalid outputs.

Keep claims descriptive: this synthetic dataset supports dashboard and SQL demonstrations, not real-world outcome recommendations.
